## Project Contents

### Company Area / Function
Ricerca e sviluppo (Research & Development)

### Training Objectives

The internship aims to foster the acquisition of methodological and technical skills in the design of advanced software services based on language models (LLMs). In particular, the intern will be guided to:

- Understand the operating principles of public LLM models and their responsible use within software architectures with security constraints;
- Develop the ability to semantically analyze and classify user requests in multilingual and multi-channel scenarios (text input and, subsequently, voice input);
- Design software flows capable of minimizing the transmission of data to external services, in compliance with data protection and privacy-by-design criteria;
- Integrate heterogeneous tools (local scripts, MCP services, AI models) within a coherent, secure, and scalable workflow;
- Develop autonomy in technical documentation, evaluation of design choices, and functional validation of developed solutions.

### Activities Carried Out

The intern will be involved in the following activities, organized in progressive phases:

1. **Requirements Analysis and Architecture Definition**
   - Study of the problem of intercepting user requests and the related linguistic, semantic, and security implications.
   - Analysis of the proposed workflow and the interaction modalities between the local service, the LLM model, and external components.

2. **System Design**
   - Modeling of the request classification flow and definition of data minimization criteria.
   - Definition of configurations for the recognition of pre-configured requests via public LLM.

3. **Application Service Development**
   - Implementation of the module that sends to the LLM model only the information necessary for semantic classification.
   - Development of the logical interface that, upon recognition of a pre-configured request, activates a script or an MCP server for executing the response.

4. **Testing, Validation, and Refinement**
   - Verification of the correct functioning of the system with real and simulated requests.
   - Progressive testing on multilingual input and, in a subsequent phase, voice input.

5. **Final Documentation**
   - Drafting of the technical documentation of the architecture and workflow.
   - Production of a final report on the design choices made and the critical issues encountered.

### Expected Competencies

At the end of the internship, the student should have acquired:

- Skills in designing software architectures that integrate LLM models in a secure, responsible, and data-minimization-compliant manner;
- Ability to implement AI-based semantic classification systems for user requests;
- Skills in developing application services capable of interacting with local scripts or MCP services, integrating them into automated decision flows;
- Familiarity with natural language processing (NLP) techniques, including multilingual contexts;
- Skills in functional validation of AI-driven systems and in drafting professional technical documentation;
- Ability for critical analysis of one's own design choices and their technical and operational implications.

### Learning Verification Methods

Learning assessment will take place through:

- Periodic reviews with the company tutor, focused on project progress and coherence with the training objectives;
- Evaluation of the logical structure of the service and the correctness of implemented flows;
- Functional tests on real and simulated cases, to verify the system's ability to correctly classify requests and activate the expected actions;
- Delivery of a final technical report illustrating methodology, results obtained, critical issues encountered, and competencies acquired;
- Possible final presentation of the project to the company and university tutors.
